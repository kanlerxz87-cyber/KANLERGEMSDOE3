## 2. The metric makes deletion profitable (ALGEBRA)

The official score is the distance-weighted Tversky index with α = 0.2 (FP price), β = 0.8 (FN
price), and a 300 m triangular kernel `k(d) = max(1 − d/3px, 0)`. Because `FNw ≡ |G| − TPw`
(|G| = hidden-truth pixels), the score collapses to one identity:

```
DTI = TPw / ( 0.2·(TPw + FPw) + 0.8·|G| )
```

Deleting a set of dots changes TPw by −t (lost unique kernel credit, t ≥ 0) and FPw by −f (removed
false-positive mass, f ≥ 0). The score rises iff the deleted dots were **FP-dominated**: roughly,
iff `t / (t+f)` is below the file's overall TP share. Two owner-reported equations
(44,090 dots → 0.2600; 37,654 dots → 0.2778) cannot uniquely determine (TPw, FPw, t, f, |G|), so
`cpx_forensics` solves the *feasible band*: for assumed |G| ∈ {8k, 10k, 12,691, 15k} and
(TPw+FPw) ∈ [0.85N, N], the implied lost credit from deleting all 6,436 near-catalogue dots is
**t ≈ 1–82 weighted pixels (≤ ~2% of TPw ≈ 3.6–4.4k)**, while removed FP mass is **f ≈ 4.5–6.4k**.
Assumed |G| ≥ 20k admits no feasible solution under those bounds, independently corroborating the
repo's lattice-calibrated estimate that the hidden population is O(10⁴) pixels, not O(10⁵).

**Conclusion 1.** The 6,436 dots within 200 m of mapped faults were almost pure false-positive mass
*against the hidden truth*. Removing them shrank the denominator by ~0.2·f ≈ 1,000+ while costing
almost no numerator. That — and only that — is why pure deletion scored higher.

## 3. What this reveals about the hidden truth (inference, with limits)

Organizer staff state that only *exact* known-fault pixels are masked in scoring; truth pixels may
in principle sit 100 m from a mapped trace. Yet empirically, essentially no scored truth was uniquely
covered by 6,436 dots packed into the 0–200 m catalogue shell. The parsimonious reading is that the
hidden set consists of **structurally distinct, genuinely off-catalogue faults** (new mapping), not
unmapped slivers hugging known traces. Two caveats keep this honest: (i) the inference is from
owner-reported scores without receipts; (ii) near-catalogue dots also suffer kernel redundancy —
neighbouring retained dots at 223–300 m still earn partial credit (`k ≈ 0–0.26`) for any shell truth —
so the algebra bounds, but does not zero, possible shell truth.

Three largely independent emission laws follow, each visible across the ~100-submission history:

1. **Spacing ≈ kernel scale.** Dots closer than ~2–3 px have overlapping 300 m coverage discs; the
   second dot adds ≈0 TPw but full FPw risk. Every top file is a thinned/Poisson "dotted" set;
   the one continuous twin of the same 44,090 geometry scored 0.0041, and the dense 206,895-dot
   lattice only 0.0904 (both OWNER-REPORTED).
2. **A ≥2 px catalogue collar is free FP removal** (until it isn't — wider collars were not
   isolated by any receipt-bound ablation, and this repo's buffered holdout *cannot* test collars
   < 1.5 km, see §4).
3. **Budget ≫ |G|.** With |G| ≈ 10⁴ and N ≈ 3.8·10⁴ dots, most dots *must* be false positives;
   the game is ranking quality in the far tail plus denominator discipline, not coverage volume.

## 4. The holdout inversion — why repo "best" models kept losing (HOLDOUT-DTI)

Scoring the *static* historical dots on this repo's hide-and-recover folds (whole catalogue
components withheld; static files are leaky by construction and shown only as geometry benchmarks):

| Static file | DTI on holdout folds | Owner-reported LB |
|---|---|---|
| GEMSDOE30 (44,090 dots, shell included) | 0.1616 [0.151, 0.172] | 0.2600 |
| GEMSDOE32 (37,654 dots, shell deleted) | **0.0067** [0.006, 0.007] | **0.2778** |

The same 6,436 dots carry ~96% of catalogue-recovery credit and ~0% of leaderboard credit.
Hide-and-recover therefore measures a *different population* than the leaderboard: it rewards
catalogue mimicry, while the prize rewards discovery away from the catalogue. This single fact
explains the graveyard of supervised submissions (0.02–0.16 reported) that were validated by
catalogue recovery, and it caps what any holdout — including this session's — can certify about
leaderboard rank. It does **not** make holdout useless: it remains the leakage canary and the
paired-comparison instrument for *fault-likeness*. It must simply never be read as a leaderboard
estimate. (For the same reason, SGMC off-catalogue faults were tested as an alternative truth:
all nine focus winners score PROXY-DTI 0.093–0.101 with DOE32 mid-pack — SGMC does not rank the
leaderboard winners either, so it is reported but never selected on.)

## 5. Can a new file beat 0.2778? (judgement)

Plausibly yes, certifiably not yet. The available levers, in expected-value order:

1. **Surface ranking in the off-catalogue tail** — the only lever with large headroom. The winning
   surface is an unsupervised ridge rank; a better-calibrated discovery ranking (label-free
   multi-physics coincidence, basement/strain structure under cover) is where a real gain lives.
   This session's CPX fusion is one such attempt: unique (≤55.3% 3-px overlap vs every genuine
   registry detector; 37.5–42.2% vs each focus winner) but it *failed* its preregistered
   catalogue-recovery gates (HOLDOUT-DTI 0.1106 [0.100, 0.121] vs ATSC's recorded 0.1637), so per
   protocol it must not consume a slot. Its holdout deficit neither proves nor disproves
   leaderboard value — §4 cuts both ways.
2. **Emission micro-efficiency** — kernel-exact allocation vs fixed spacing was worth
   −0.0047 ± 0.002 HOLDOUT-DTI here (paired, i.e. the FP-priced greedy *lost* to spacing CELF on a
   rank-fused surface). Second-order.
3. **Budget/collar retuning** — already at the empirically proven point (37,654 / b2); holdout
   cannot tune these for the leaderboard because its truth is ~5× denser and on-catalogue.

Noise floor: near-identical DOE28-family masks span 0.2649–0.2710 owner-reported, so differences
below ~±0.01 between cousins are not interpretable without receipts. Beating 0.2778 *verifiably*
requires a genuinely better off-catalogue ranking, submitted once, with the receipt bound to bytes.
