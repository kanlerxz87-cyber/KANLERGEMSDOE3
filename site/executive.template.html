01 BEFORE YOU BEGIN

Separate the gates.

A readable TIFF is only the first part of a safe submission. Nothing below authorizes a slot on its own.

01   GeoTIFF format

One float32 band, same CRS, dimensions and geotransform as the authentic sample; prediction values in [0,1]. The written specification says outside bounds should be null or NaN.

02   Scientific evidence

Check each feature for leakage, use visible-only whole-segment buffered holdouts, and compare pooled DTI with a matched control and paired 95% confidence interval.

03   Genuine uniqueness

Check the actual pre-placement surface and final support against the complete applicable registry. Missing evidence is unknown, not a pass.

04   Separate slot decision

Only a later selector may approve a candidate and check the actual account quota. This project did not select or use a slot.

02 IF A FUTURE FILE IS APPROVED

How to submit it.

  1. 1

    Download the approved file

    Choose the exact named single-band .tif, or a .zip containing only that TIFF. Verify the downloaded file's SHA-256 against its receipt. The filename identifies the submission; do not assume the form has a separate name field.

  2. 2

    Open DrivenData

    Sign in and enroll, then select Submit → Make new submission on the official competition page. Authentication is not available to this project.

  3. 3

    Attach the file and a short note

    In File to submit, select the TIFF or single-TIFF ZIP—not this page or a report. Paste the candidate's unique, descriptive note (this project limits it to 140 characters). No candidate name or note exists yet.

  4. 4

    Check the quota and submit

    Check the account's actual remaining quota on the submission page. The published rules state up to three feedback submissions per week, as specified on the competition website; select one final submission for both rounds.

  5. 5

    Save the receipt

    Keep the exact filename, file hash, note, timestamp, and organizer score/receipt together. A local holdout result is not a competition score.

03 TROUBLESHOOTING

Range error: what to check.

The prior error “Predicted values must be in range [0, 1]” does not establish its cause. Inspect the saved TIFF—not the source array—for negative values, values above one, infinities, NaNs inside the footprint, and an invalid nodata sentinel. Confirm that the selected file is the TIFF rather than a document.

The shared local validator applies an all-finite policy and checks the full grid, but the public written specification also calls for null/NaN outside bounds. No portal acceptance of either encoding has been verified here. Never silently clip or replace scientific predictions just to make a file pass.

python scripts/bootstrap.py --data
python scripts/validate_raster.py path/to/file.tif

These commands check a local file against the owner-mirror grid. A format pass is not a uniqueness, holdout or submission approval.
