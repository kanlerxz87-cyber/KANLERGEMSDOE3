What to test next

  1. Multi-scale DEM directional curvature breaks (first priority): target persistent terrain curvature discontinuities; test lithologic contacts, drainage edges, and human terrain change as mimics.
  2. Magnetic analytic-signal edge concordance: target linear basement magnetic boundaries; explicitly screen flight-line artifacts.
  3. Drainage deflection/offset: target channel azimuth changes and knickpoints; control for erosion and lithology.
  4. Radiometric–magnetic–terrain interaction: conditional co-location of independent physical signatures; verify source channels/metadata first.
  5. Lineament intersection/termination network: test intersection topology; overlap risk with existing tip/stepover approaches is high.

These are proposals only. This empty checkout has no local implementation to compare against and no holdout data to validate them. See the full README for risks, protocol and source links.

Exact download-to-submit gate

A submission may be marked OK TO DOWNLOAD only after it passes: one-band float32 GeoTIFF; EPSG:32611; exact organizer shape/transform; finite in-footprint values in [0,1]; correct null/nodata outside; blocked holdout improvement with evaluator version, withheld-positive count and 95% CI; leakage canary; and registry-raster duplicate checks before and after placement. A projection is not a score. Slot promotion is a separate selector decision.
