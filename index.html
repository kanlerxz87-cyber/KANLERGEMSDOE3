Submission format reference

The official challenge describes a single-band float32 GeoTIFF on the training grid, EPSG:32611, 100 m, values from 0 to 1, null/NaN outside the footprint; it defines distance-weighted Tversky with α=0.2, β=0.8 and a 300 m triangular kernel. Review the official competition description and organizer reference solution.

Format validity does not imply scientific quality, uniqueness, leaderboard performance, or approval to submit.
