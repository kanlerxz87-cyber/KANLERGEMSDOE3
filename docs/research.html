Reuse an identified, hash-pinned shared template cache, `evaluate_holdout.py`, and `submission_writer.py`. Retrieved upstream source files are evidence only; no private evaluator fork was created. An upstream defect must be fixed in its shared template before adoption. 2. Freeze whole fault segments and spatial blocks with buffers. For each fold, discard all hidden-fault-derived features, rebuild every catalogue feature from visible segments, and mask only visible faults pixel-exactly. Audit all inputs including exclusion masks for hidden-label leakage. 3. Test every feature individually. An AUC above the specified canary threshold blocks trust until leakage is disproved; a lower AUC does not prove absence of leakage. Report background sampling and spatial confidence intervals. 4. Compare candidate and incumbent on exactly the same folds, domain and evaluator. Report pooled HOLDOUT-DTI with evaluator version, withheld-positive count and segment/block bootstrap confidence intervals, plus a paired improvement interval. Do not average fold ratios as a substitute for pooled counts. Use the requested triangular distance kernel and weighting, verified against the official implementation before release. 5. Check every registry raster on the continuous surface before placement, then final dots. Stop as duplicate if the literal correlation or proximity threshold is breached. Do not exempt dense calibration lattices silently; flag if these make the protocol infeasible. SHA difference alone is never geological uniqueness. 6. Validate the saved GeoTIFF bytes against the actual template: one band, exact CRS, dimensions and transform; finite `[0,1]` predictions inside the footprint; and outside-mask/null encoding matching the official sample/schema. A finite-zero outside convention reported by some participant pages conflicts with the official page's null/NaN description; do not change encoding to silence a range error without checking the sample/validator. A local pass does not guarantee portal acceptance. 7. Maximum three experiments or two hours; stop on duplicate. Promotion requires a same-evaluator holdout win, not an owner score or projection.
