The command sandbox network was limited to GitHub and package registries. Official pages were read with the
web tool, not authenticated or downloaded through the shell. `.cache/` contains regenerable pinned owner
mirrors and is not committed. The sample mirror's positive pixels reproduce the known catalogue; use its
grid/footprint only, never those positives as a predictor. See [hypotheses](hypotheses.html) for input
selection, confounders and remaining data-availability caveats.
