How to make a submission (executive guide)

CURRENT DECISION: DO NOT SUBMIT — yet  Do not upload the CPX research TIFF. The steps below are the exact, validated path to use once a selector approves a file and a weekly slot.

1 · Pick the approved file and verify its bytes

  1. Download the selector-approved -zeros.tif (or its .zip) from this portal.
  2. Verify SHA-256 matches the run card before uploading: sha256sum kanlergemsdoe3-h-cpx1-edti-fusion-37654-20261028-c170892fad1f-zeros.tif → for the CPX research file: dd94527ee42a484763e1cb4645bd9aee94ace4e483af91497e57c6f3553dbbce.

2 · Why you will not see “Predicted values must be in range [0, 1]”

That portal error fires when a whole-array scan finds NaN, nodata sentinels, or values outside [0,1]. The -zeros encoding writes finite values in [0,1] in every one of the 12,279,160 cells (0 outside the study footprint, verified on saved bytes: min 0.0, max 1.0, 0 NaN). A -nan twin (NaN outside footprint, matching the literal sample) is shipped alongside. Upload one of them — the -zeros file is the primary deliverable; both contain identical predictions inside the footprint.

3 · Upload on DrivenData

  1. Open the competition page, sign in, check your remaining weekly submissions (rules: 3/week — verify live).
  2. Submit → Make new submission. Choose the single .tif (or a .zip containing exactly one GeoTIFF — both provided).
  3. Paste the run-card note into Note (≤140 chars). For CPX: CPX coincident grav-mag-strain fusion + exact E-DTI emission 37.7k dots b2 c170892fad1f
  4. Submit, then record the organizer receipt and bind it to the file SHA-256 — only that receipt creates an ORGANIZER-CONFIRMED score.
