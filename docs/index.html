How to make a submission (no manual inspection)

  1. Read the verdict banner above. If it says DO NOT SUBMIT, stop — downloading is for research only.
  2. Download the -zeros.tif above (or its ZIP). Never upload a -nan variant: NaN outside the footprint triggers “Predicted values must be in range [0, 1]”.
  3. Locally re-validate: .venv/bin/python scripts/validate_submission.py docs/downloads/<file>-zeros.tif must print PASS and portal_range_ok: true.
  4. On DrivenData → Submit: choose the file, paste the submission name and the ≤140-character note shown above, submit once. A resubmission spends a slot and adds no information.
  5. Record the receipt; only a submission-page receipt upgrades a score to ORGANIZER-CONFIRMED.
