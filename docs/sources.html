Known-fault masking ↗

Staff state that pixels corresponding to existing known faults are excluded in both scoring rounds. This is not a statement that an arbitrary surrounding buffer is excluded.

Scientific data catalog

USGS · CC0 as stated in release

GeoDAWN magnetic and radiometric surveys ↗

High-resolution airborne magnetic and radiometric data in the northwestern Great Basin. Official landing page retrieved. The sandbox used SHA-pinned owner-mirrored competition features, not a fresh official raw download.

USGS · free, without use restrictions

3D Elevation Program ↗

LiDAR-derived elevation data and access tools. The official page says 3DEP products are free and without use restrictions. Local coverage and preprocessing must be verified for each tile.

DOE GDR / INGENIOUS · CC BY 4.0

Great Basin regional compilation ↗

Public metadata lists well/spring, 2-m temperature, paleogeothermal, fault and other layers. The landing page identifies CC BY 4.0 and requires attribution; it was retrieved, but raw downloads and coverage for each proposed use were not independently tested in the restricted shell.

USGS · official fault database

Quaternary Fault and Fold Database ↗

Existing mapped faults and nontectonic alternatives, including landslides and erosional scarps. Data are incomplete and cannot serve as a catalogue of all true faults.

USGS publication · interpretation caution

Non-unique potential-field interpretation ↗

Saltus and Blakely describe why gravity and magnetic anomalies can have multiple geological interpretations. A geophysical edge by itself is not proof of faulting.
