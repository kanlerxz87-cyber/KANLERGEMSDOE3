## Why 0.2778 might be higher (carefully bounded explanation)

The official metric weights distance with a 300 m triangular kernel and uses α=0.2, β=0.8. That makes false negatives costlier than false positives in the specified denominator, but false-positive mass still matters. If two prediction sets cover similar recoverable fault length, removing redundant/off-target predictions can improve the ratio by lowering the false-positive term more than it lowers weighted true positives. This provides a plausible *mechanistic explanation* for why a thinner map could outperform a denser ancestor.

The pinned raster comparison verifies H33 B2 has 37,654 positive pixels and is a strict in-footprint subset of the audited GEMSDOE31 40,199-dot winner, deleting 2,545 and adding none. This establishes geometric lineage only: aggregate score cannot tell whether removed points were false alarms or missed faults. The 0.2778 claim remains OWNER-REPORTED without receipt-to-hash linkage. A receipt or valid spatial hide-and-recover/controlled ablation is needed for score provenance and causal interpretation. The official leaderboard fetched 2026-10-26 showed 0.4437 at rank 1; this is a dated public value, not a private/final result or estimate for a new candidate.
