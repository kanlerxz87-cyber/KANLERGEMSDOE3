Exact submission steps

Any failure = DO NOT SUBMIT.
  2. Download the -zeros.tif (single-band float32, EPSG:32611, 3730×3292, transform 100 m, outside-footprint = 0, no NaN anywhere).
  3. Re-validate locally (automated, seconds): scripts/validate_submission.py.
  4. DrivenData: Competitions → DOE GEMS → Submit → choose file → Name = the unique submission name above → Note = the ≤140-char note above → Create submission.
  5. Save the receipt. Only then may a score be called ORGANIZER-CONFIRMED in this repo.

Why “-zeros”: the official sample carries NaN outside the footprint; some portal checks read the whole array. Scored historical files prove the zeros encoding is accepted (e.g. the 0.2778 and 0.2750 OWNER-REPORTED files are themselves -zeros variants), while a NaN file can return “Predicted values must be in range [0, 1]”.
