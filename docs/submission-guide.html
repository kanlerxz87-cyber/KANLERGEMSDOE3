Fixing the range error

Check the saved raster cell-by-cell.

The official format requires values from 0 to 1 and null/NaN outside bounds. No NaN/Inf inside the footprint; every finite inside value must be within [0,1]. Check the output after writing, not only the model array.

Some peer pages report using zero outside to avoid a portal range error, but this conflicts with the official null/NaN outside-bounds description. Compare the authorized sample template and validator before choosing an encoding. Local validation cannot guarantee acceptance.

  • One band, float32: required
  • CRS/shape/transform exact: required
  • Footprint finite, values [0,1]: required
  • Outside mask follows sample: required
  • Receipt bound to TIFF SHA-256: required to confirm score

Portal steps after separate approval

One file, one note, one carefully chosen slot.

  1. Sign in at the official DrivenData GEMS competition.
  2. Open New submission and choose the exact approved TIF (or a ZIP containing one TIFF if allowed).
  3. Enter a unique name and concise note (≤140 characters).
  4. Check the weekly cap. The experiment does not select or spend a slot.
  5. Save the portal receipt and bind its reported score to the exact TIFF hash.
