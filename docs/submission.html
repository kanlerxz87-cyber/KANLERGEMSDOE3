5. If you get the "[0, 1] range error"

The DrivenData portal error "Predicted values must be in range [0, 1]" occurs when any pixel value (including outside the footprint) falls outside [0, 1]. The zeros variant of this file sets all outside-footprint pixels to exactly 0.0, so the entire grid satisfies (arr >= 0) & (arr <= 1). Do not use NaN outside the footprint unless you have confirmed the portal accepts it.
